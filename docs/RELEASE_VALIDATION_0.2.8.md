## 확인하지 않은 범위와 제한

- 실제 계정으로 메시지 전송·서버 읽음 변경을 실행하지 않았습니다. 기존 읽기 전용 API 제한을 유지합니다.
- 실제 서버 메시지 클릭/읽음 이벤트, Windows 재부팅·로그오프, 장시간 안정성은 이번 배포 검증에 포함하지 않았습니다.
- 모든 창보다 항상 위에 보임, 멈춘 프로세스의 복구, 복구 프로세스까지 함께 종료되거나 보안 프로그램에 차단된 경우의 복구를 보장하지 않습니다.
- 이전 사라짐의 마지막 종료 원인은 기록 부족으로 확정하지 못했습니다. 이번 수정은 예기치 않은 주 프로세스 종료에 대응합니다.
- 코드 서명 없는 테스트 버전입니다. 같은 Windows 사용자 계정에서 사용해야 기존 암호화 토큰을 복원할 수 있습니다.
