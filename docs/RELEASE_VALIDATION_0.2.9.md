- 실제 서버 메시지 클릭/읽음 이벤트, Windows 재부팅·로그오프 및 장시간 안정성은 이번 배포 검증에 포함하지 않았습니다.
- 시작 프로그램 등록은 로직 테스트로 확인했습니다. 실제 로그인을 반복한 검증은 아닙니다.
- 앱과 감시자가 함께 종료되거나 실행이 차단된 경우, 살아 있는 프로세스가 멈춘 경우의 자동 복구를 보장하지 않습니다.
