# 업데이트 알림 — 0.2.10

앱 시작 15초 후 및 6시간마다 공식 공개 GitHub 릴리스 최근 100개를 확인합니다. 테스트 버전도 포함하며, 현재 버전보다 높고 공식 Windows x64 ZIP 업로드가 완료된 릴리스만 안내합니다. 버전은 문자열 순서가 아닌 숫자 및 사전 공개 버전 순서로 비교합니다.

- Windows 알림은 새 버전마다 한 번 시도합니다. 알림 클릭은 앱 설정 창을 엽니다.
- 앱 상단 배너와 캐릭터 ↑ 표시는 '나중에'를 누를 때까지 유지됩니다. 숨김은 다음 실행에도 유지됩니다. 이후의 새 버전은 다시 표시합니다.
- 상단 '업데이트 확인'은 직접 확인하고 숨긴 버전도 다시 볼 수 있게 합니다. 연속 클릭은 1분 동안 요청을 재사용합니다.
- 다운로드 및 변경 내용 버튼은 검증된 공식 GitHub URL만 엽니다. 자동 설치나 앱 강제 종료는 하지 않습니다.
- GitHub에는 인증 없는 GET 요청만 보내며 Rocket.Chat의 서버 주소·계정·토큰·메시지는 전달하지 않습니다. 회사 연결과 별도 요청 경로입니다.
- 실패 시 기존 메시지 기능을 유지하며 다음 확인 때 재시도합니다. 최근 알려진 업데이트가 있으면 최근 확인 실패임을 함께 표시합니다.
- 알림 상태는 사용자 프로필의 updates.json에 버전명만 저장합니다. 기존 state.json/credential.bin은 변경하지 않습니다.

API 근거: [GitHub Releases 공식 문서](https://docs.github.com/en/rest/releases/releases#list-releases). 공개 릴리스 조회는 인증 없이 지원됩니다.

v0.2.10부터 제공됩니다. 이전 v0.2.9 ZIP에는 이 기능이 없습니다. Windows의 알림 설정에 따라 시스템 알림이 표시되지 않을 수 있으며 이때도 앱 배너와 ↑ 표시를 사용할 수 있습니다.

검증: 단위·통합 테스트 57개 통과. 격리 프로필 EXE에서 가상 새 버전의 배너·공식 다운로드 링크·숨김·기존 메시지 보존을 확인했고, 실제 공개 API에서 v0.2.9 테스트 릴리스를 찾았습니다. 가상 알림 테스트는 실제 GitHub에 새 릴리스를 만들거나 실제 계정을 변경하지 않습니다. Windows 시스템 알림 전달 여부는 사용자 OS 알림 설정에 따릅니다.
