# 종료 복구 수정 — 0.2.8

2026-11-02 수정. 공개 ZIP 검증 결과는 RELEASE_VALIDATION_0.2.8.md를 참고하세요.

## 확인된 상태

- 보고 시 RocketPet 프로세스가 없었으며, Tikki는 실행 중이었습니다.
- 자동 시작 경로는 이전 0.2.6 설치본을 가리켰습니다.
- 계정·규칙·외형·암호화 토큰 파일은 보존돼 있었습니다.
- 이전 로그에는 정상 기동과 토큰 복원 기록만 있었고 마지막 종료의 원인은 확인되지 않았습니다.
- Tikki의 네이티브 Windows 시작 등록/창 수명 코드를 읽기 전용으로 참고했습니다. 원본을 수정하거나 복사하지 않았습니다.

## 변경

- 앱과 별도로 실행되는 감시 프로세스가 예상치 못한 주 프로세스 종료를 감지하면 약 2초 이후 재실행합니다.
- 종료 메뉴, 창의 정상 앱 종료, Windows 세션 종료에서는 감시를 해제합니다.
- 반복 충돌 시 무한 실행을 막기 위해 10분 동안 최대 3회만 재실행합니다.
- 기존 사용자 데이터 폴더를 그대로 사용합니다. 메시지나 토큰을 감시 프로세스에 전달하지 않습니다.
- 1분마다 창 표시 여부만 진단 로그에 기록합니다.

## 검증

- 단위/통합 테스트 49개 통과: 실제 별도 프로세스 강제 종료 후 대체 프로세스 실행 포함.
- 격리된 Electron 프로필에서 강제 종료 후 재실행·창 생성 확인, 정상 종료 후 감시 프로세스와 실행 표시 파일 제거 확인.
- 패키징한 EXE smoke 테스트 통과: 캐릭터/설정 저장, 드래그, 호버 정지, 여러 말풍선, 원본 링크, 로컬 확인/복구, 렌더러 충돌 복구.
- 연결된 두 모니터에서 위치 변경 및 화면 안 배치 검증 통과.
- 실제 Windows 재부팅/로그오프는 이 작업 중 시행하지 않았습니다.

## 제한

복구 프로세스까지 함께 종료하거나 보안 프로그램이 실행을 차단하면 자동 복구를 보장할 수 없습니다. 프로세스가 살아 있는 채 멈춘 경우는 이번 복구 대상이 아닙니다. 마지막 종료 원인이 밝혀진 것은 아니며, 장시간 안정성은 추가 관찰이 필요합니다.
