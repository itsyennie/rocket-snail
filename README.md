# Rocket Snail — Rocket Pet for Windows

**바탕화면의 작은 달팽이가, 내가 확인해야 할 Rocket.Chat 메시지를 말풍선으로 보여 줍니다.**

메시지가 많이 오는 회사 메신저에서 중요한 내용을 놓치기 쉬운 분을 위한 Windows 앱입니다. 방마다 어떤 메시지를 챙길지 정해 두면, 조건에 맞는 메시지를 모아 보여 줍니다.

## 어떻게 쓰나요?

1. **챙길 메시지를 정합니다.** 공지방은 모든 메시지, 다른 방은 내 멘션만 받도록 설정할 수 있습니다. `마감`, `검토 요청` 같은 키워드도 추가할 수 있습니다.
2. **달팽이의 말풍선을 확인합니다.** 조건에 맞는 새 메시지가 오면 바탕화면에 표시됩니다.
3. **말풍선을 누르면 원본으로 이동합니다.** PC에 설치된 Rocket.Chat 앱에서 해당 메시지를 엽니다.
4. **서버의 읽음 정보가 확인되면 목록에서 자동 정리합니다.** 말풍선을 눌렀다는 이유만으로 메시지를 없애지 않습니다. 읽었는지 확실하지 않으면 확인 대기 목록에 남겨 둡니다.

예를 들어, **공지방의 새 글 + 나를 부른 메시지 + ‘마감’이 들어간 메시지**를 한곳에서 챙길 수 있습니다. 같은 메시지가 여러 조건에 맞아도 한 번만 표시합니다.

## 무엇을 설정할 수 있나요?

| 원하는 동작 | 설정 |
| --- | --- |
| 방마다 챙길 메시지를 다르게 정하기 | 모든 메시지 / 멘션만 / 무시, DM 별도 설정 |
| 특정 단어가 들어간 메시지 챙기기 | 전체 방 또는 특정 방에 키워드 추가, 제외어 설정 |
| 달팽이 꾸미기 | 껍데기 무늬·색, 몸통 색, 눈 모양, 크기 변경 |
| 원하는 화면에 두기 | 모니터 선택, 드래그 이동, 상하좌우 가장자리 이동 |
| 움직임 줄이기 | 움직임 끄기, 마우스를 올리거나 설정 창을 열면 일시 정지 |
| 자동 정리된 메시지 다시 보기 | 최근 자동 정리 내역에서 복구 |

## 다운로드와 준비물

- **Windows x64 PC**와 **설치된 Rocket.Chat 데스크톱 앱**이 필요합니다.
- [최신 배포 목록](https://github.com/itsyennie/rocket-snail/releases)에서 Windows ZIP을 받고 **전체 압축을 해제한 뒤 `RocketPet.exe`를 실행**하세요.
- 처음 실행하면 본인이 사용하는 **Rocket.Chat 서버 주소, 사용자 ID, 개인 접근 토큰**을 입력합니다. 개인 접근 토큰은 앱이 본인 계정의 메시지를 읽는 데 사용하는 인증 수단입니다. 조직에서 발급과 사용을 허용해야 합니다.

이 앱은 Rocket.Chat 공식 제품이 아닌 독립 보조 앱입니다. 메시지를 보내거나 Rocket.Chat의 읽음 상태를 바꾸지 않습니다. 토큰은 Windows에서 암호화해 저장하며, 메시지 일부와 설정은 PC에 저장합니다. 현재는 코드 서명 없는 테스트 버전입니다.

## 바로 실행

`dist/RocketPet-Windows-x64/RocketPet.exe`를 실행하세요. 배포 폴더 전체가 필요합니다. EXE 하나만 다른 곳으로 옮기면 실행되지 않습니다. 설치·관리자 권한은 필요하지 않으며, 아직 코드 서명한 정식 배포판은 아닙니다.

1. **연결·캐릭터** 화면에서 HTTPS 서버 주소, 사용자 ID와 개인 접근 토큰을 입력합니다. Rocket.Chat의 본인 계정에서 발급받은 값을 사용하며, 이 채팅이나 소스 파일에 넣지 않습니다. 회사 정책상 토큰 사용이 허용되고 해당 메뉴가 제공되어야 합니다.
2. **저장하고 연결**을 누릅니다. 계정 확인이 성공하면 본인이 구독한 방 목록을 읽어 옵니다.
3. **방과 키워드**의 **기본 메시지 설정**에서 일반 방·DM의 기본값을 정합니다. **방마다 개별 규칙 적용하기**를 펼치면 방별 수신 방식을 지정하거나 기본 설정을 따르게 할 수 있습니다. 별도의 **키워드 설정**에서 키워드를 적용할 곳을 선택하고 단어를 추가한 뒤 **변경사항 저장**을 누릅니다.
4. 설정 창의 **×**를 누르면 설정 창이 닫히고 캐릭터는 선택한 위치에 남습니다. 캐릭터를 누르면 목록·설정, 말풍선 또는 **데스크톱 앱에서 열기**를 누르면 설치된 Rocket.Chat 앱에서 원본 메시지가 열립니다.

달팽이를 마우스 왼쪽 버튼으로 누른 채 드래그하면 가로·세로 위치를 옮길 수 있습니다. 짧은 클릭과 드래그는 5px 이동 기준으로 구분하고, 드래그 뒤에는 설정 창을 열지 않습니다. 놓은 위치는 자동 저장해 다시 실행할 때 복원합니다. 움직임을 꺼둔 상태에서도 드래그할 수 있습니다. 자유 위치 모드에서는 움직임이 켜져 있으면 놓은 높이에서 다시 좌우로 걷습니다. 가장자리 모드에서는 놓을 때 선택한 가장자리에 붙습니다. 다른 모니터로 끌면 마우스가 있는 모니터의 작업 영역을 사용하고, 화면 가장자리에서는 말풍선이 위나 아래에 보이도록 배치합니다.

**연결·캐릭터 → 캐릭터 움직이기**를 끄면 현재 위치에서 걷기와 애니메이션을 모두 멈춥니다. 즉시 저장되며 앱을 다시 실행해도 유지됩니다. 시스템 트레이 메뉴의 **캐릭터 움직이기**로도 켜고 끌 수 있습니다. 정지 상태에서도 메시지 수집과 말풍선은 계속 동작합니다.

마우스를 달팽이 위에 올리면 위치 이동과 껍데기 애니메이션을 즉시 일시 정지합니다. 마우스를 떼면 움직임 설정에 따라 다시 움직이며, 호버는 저장된 움직임 설정을 바꾸지 않습니다.

설정 창이 열려 있는 동안에도 달팽이의 이동과 애니메이션을 멈춥니다.

**달팽이 꾸미기** 탭에서 껍데기 무늬(소용돌이·물방울·줄무늬·별·민무늬), 껍데기 색, 무늬 색, 몸통 색, 눈 모양(동그란 눈·웃는 눈·졸린 눈·반짝이는 눈)을 조합할 수 있습니다. 색은 추천 색상이나 색상 선택기로 고릅니다. 선택은 미리보기에 바로 표시되며 **적용하고 저장**을 누르면 바탕화면 캐릭터에 반영되고 다음 실행에도 유지됩니다. **기본 모습으로**는 미리보기를 원래 모습으로 되돌립니다. 적용하려면 저장을 누르세요. 꾸미기 저장은 계정 연결을 다시 시작하지 않습니다.

꾸미기 탭에서는 오른쪽의 껍데기·몸통·눈 설정 영역만 스크롤됩니다. 제목, 왼쪽 미리보기, 하단 저장 버튼은 고정됩니다.

종료는 설정 창의 **종료** 또는 시스템 트레이 메뉴를 사용합니다. Windows 시작 시 실행은 기본으로 꺼져 있으며, 옵션을 저장할 때만 변경합니다. 이 테스트 버전은 한 서버·한 계정 사용을 전제로 합니다.

## 확인 동작

- 기본값: 일반 방은 멘션 또는 키워드, DM은 모든 메시지. 본인이 보낸 메시지는 수집하지 않습니다.
- 8.5의 `mentions` 배열에서 개인 사용자 ID, `{_id:'all',username:'all'}`, `{_id:'here',username:'here'}`를 구분합니다. 본문 문자열 `all`이나 일반 텍스트 `@all`만으로 멘션을 추측하지 않습니다. 8.5 공식 서버 코드는 `@here`도 구독자의 그룹 멘션 카운터에 반영합니다. 온라인 사용자에게 보내는 알림과 Pet의 확인 대기 목록은 다른 기능입니다.
- 키워드는 전역/방별 설정, 포함/유니코드 단어 경계/정규식, 대소문자, 제외어, 우선순위, 켜기/끄기를 지원합니다. 제외어는 해당 키워드에만 적용되며 멘션을 취소하지 않습니다. 높은 우선순위 키워드부터 평가하고, 멘션과 키워드는 OR로 합칩니다. 동일 메시지는 하나만 저장합니다.
- 정규식은 200자 제한, 평가 시간 제한 25ms를 둡니다. 시간 초과한 정규식은 그 메시지에서 일치하지 않은 것으로 처리합니다. 한글은 NFC로 정규화합니다.
- 캐릭터 클릭이나 링크 열기만으로 메시지가 없어지지 않습니다. 30초마다 읽어 온 서버 구독의 `ls`가 메시지 시각보다 뒤일 때 자동 정리합니다. 같은 시각·유효하지 않은 시각·구독 정보 없음은 보류합니다. 방 단위 읽음으로 개별 스레드 답글의 읽음을 확정하지 않으며, 현재 모든 스레드 답글은 보류합니다.
- 최근 자동 정리는 7일 또는 최대 100개까지 복구할 수 있습니다. 복구한 항목은 같은 읽음 정보가 반복되어도 유지하며, 이후 읽음 시각이 갱신되어야 다시 자동 정리됩니다.
- Rocket.Chat 읽음 변경, 메시지 전송 API는 구현하지 않았습니다. API 호출은 고정된 읽기 전용 목록만 허용합니다.

## 버전·연결과 저장

8.5는 `channels.history`, `groups.history`, `im.history`를 사용합니다. 서버가 8.9 이상이면 `rooms.history` 커서 API를 선택합니다. 구독·방 목록과 이력은 30초 간격으로 동기화하며, 실시간은 별도 WebSocket으로 받습니다. 연결이 끊기면 1초부터 최대 60초 간격으로 재시도합니다. 이력은 고정된 시간 범위와 페이지 위치를 사용하고, 한 번에 5페이지를 넘으면 다음 동기화에서 이어갑니다. 읽음 시각을 얻지 못한 방은 처음 24시간부터 수집합니다. 서버 권한·호출 제한·장기 오프라인에 따른 이력 완전성은 실제 계정에서 검증해야 합니다.

원본 링크는 Windows에 등록된 `rocketchat://room`을 사용해 설치된 데스크톱 앱으로 전달합니다. `host`와 `rid`, 메시지 경로를 담은 `path`를 전달하며, 토큰은 URL에 넣지 않습니다. `path`에는 8.5 클라이언트의 `?msg=<id>`를 유지합니다. 공개·비공개 방은 URL용 이름, DM은 방 ID를 사용합니다. 한글로 시작하는 방 이름은 Desktop 4.18.2의 경로 검사 및 표준 URL 정규화에 맞춰 `channel/./<인코딩된 이름>` 형식을 사용합니다. 앱 실행 실패는 화면에 표시하며 브라우저로 자동 전환하지 않습니다. 로컬 설치본 4.18.2와 `rocketchat` 등록을 확인했고, 공식 소스 및 예제 데이터로 링크 경로·클릭 전달을 검증했습니다. 회사 계정의 실제 메시지 위치 이동은 아직 확인하지 않았습니다.

데이터 위치: `%APPDATA%/DexterRocketPet/`. `state.json`에는 규칙, 메시지 앞 500자, 자동 정리 기록이 일반 텍스트로 저장됩니다. 회사의 로컬 저장 정책이 적용됩니다. `credential.bin`에는 서버·계정에 결합한 토큰을 Windows DPAPI 기반 Electron `safeStorage`로 암호화해 저장합니다. 네트워크는 HTTPS/WSS만 사용하며 인증 정보를 포함한 HTTP 리다이렉트는 거절합니다. 비밀번호는 요구하지 않습니다.

## 개발 실행·검증

```powershell
npm ci
npm test
npm run smoke
npm start
npm run package
```

Node.js 22 이상, Windows x64에서 실행합니다. Electron 38.8.6을 잠금 파일로 고정했습니다. `smoke`는 별도 테스트 프로필과 예제 메시지를 사용하고, 숨김 창을 캡처한 뒤 종료합니다. 회사 계정·시작 프로그램 설정은 변경하지 않습니다.

- 29개 테스트: 8.5/8.9 API 선택, 서버 페이지 제한과 이어받기, 읽기 전용 제한, URL, 화면 양 끝 이동, 실제 8.5 멘션 형태, 한글 키워드, 영속 저장·복구, 스레드 보류, 정규식 시간 제한, 방 전용 키워드와 기본 수신 설정의 독립 적용, 데스크톱 메시지 링크·실행 전달·실패 처리, 꾸미기 설정의 이전 파일 호환·저장·입력 검증·SVG 조합, 클릭·드래그 구분, 두 축 이동, 화면 밖 이동 제한, 말풍선 배치, 위치 복원、70~150% 모든 크기에서 정지 좌표 누적 오차 방지.
- Windows Electron 실행 및 연결 화면·캐릭터 캡처 확인. `artifacts/smoke-result.json`, `artifacts/connection.png`, `artifacts/pet.png`, `artifacts/motion.png`. 움직임 끄기 후 위치 유지·애니메이션 정지·저장 파일 재읽기·움직임 재개와 헤더 버튼 제거도 검증합니다.
- 꾸미기 미리보기·바탕화면 적용·저장 파일 재읽기·다른 설정 저장 후 외형 유지·정지 설정 유지 검증. `artifacts/customize.png`, `artifacts/customize-eyes.png`, `artifacts/custom-pet.png`. 원래 SVG를 바탕으로 무늬와 표정을 새로 작성했으며 원격 자산을 불러오지 않습니다.
- 실제 서버의 공개 버전과 인증 전 WebSocket 연결 확인: `artifacts/server-check.json`.
- 미검증: 본인 계정 인증·권한, 실제 메시지 수신, 실제 읽음 변화, Windows 자동 시작 실사용, 서명·백신 배포 심사, 실제 마우스를 사용한 다중 모니터·혼합 배율 간 드래그. 드래그 좌표 계산과 위치 저장·복원은 자동 테스트로 확인했습니다. 임의 서버 확장·E2EE 본문 복호화·팀 멘션 확장은 미지원입니다.

## Tikki 참조와 독립 구현

Tikki의 Windows 렌더링·걷기·시작 프로그램 UX와 자산 구조를 읽기 전용으로 참고했습니다.

Tikki에서 확인한 원칙은 작업 영역 좌우 끝까지 이동, 보이는 발 위치를 바닥에 맞추기, 사용자별 시작 프로그램, 별도 자산 생성·배포 구조입니다. Tikki는 Go/Win32와 생성된 픽셀 자산을 사용합니다. 이 앱은 새로 작성한 Electron/JavaScript 및 달팽이 SVG를 사용하며 Tikki 코드·픽셀 배열을 복사하지 않았습니다. 바닥에 닿은 몸통을 유지하고 껍데기만 움직이며, 크기는 70–150%에서 1%씩 조절합니다.

## 모니터와 이동 위치

**연결·캐릭터 → 캐릭터 배치**에서 모니터와 이동 위치를 선택하고 **위치 적용**을 누릅니다. 하단·상단에서는 좌우로, 좌측·우측에서는 위아래로 이동합니다. 상단은 거꾸로 매달립니다. **자유 위치**는 기존처럼 드래그한 높이를 유지합니다. 설정은 자동 저장하며 선택한 모니터가 분리되면 주 모니터에 표시하고 다시 연결하면 선택한 모니터를 사용합니다. 호버 중이거나 설정 창이 열려 있으면 모든 방향에서 정지합니다.

## GitHub 배포

Releases에서 Windows x64 ZIP을 받아 전체를 압축 해제한 뒤 RocketPet.exe를 실행합니다. 최초 실행 시 서버 주소를 직접 입력합니다. 업데이트는 트레이에서 앱을 종료한 뒤 새 폴더로 교체합니다. 계정·규칙·외형은 AppData에 유지됩니다.

개발자는 npm ci, npm test, npm run smoke를 통과한 뒤 npm run release로 ZIP과 SHA-256 파일을 생성합니다. 소스 저장소에는 토큰·메시지 기록·빌드 폴더·테스트 캡처를 포함하지 않습니다. 현재 배포판은 Windows x64 휴대용 테스트 버전이며 코드 서명이 없습니다.
