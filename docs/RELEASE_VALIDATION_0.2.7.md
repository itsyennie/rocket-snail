## 배포물 검사

- v0.2.6 공개 ZIP에는 새 픽셀 기본형이 없고, v0.2.7 ZIP에는 포함됨을 비교했습니다.
- ZIP의 소스 파일 17개가 검증 대상 로컬 소스와 바이트 단위로 일치합니다.
- ZIP 엔트리 109개에 사용자 프로필·토큰·로그·예전 5종 시안을 포함하지 않았습니다.
- 소스에서 실제 회사 서버 주소·사용자 ID·사용자 경로 패턴을 검사했고 발견되지 않았습니다.
- LICENSE.md·THIRD_PARTY_NOTICES.md는 원본과 일치합니다. Electron의 LICENSE 및 LICENSES.chromium.html도 유지됩니다.
- PNG의 투명 배경을 검사했습니다. 실제 메시지 대신 가상 예시만 사용하며 재구성 표시가 있습니다.
